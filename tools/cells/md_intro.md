# AODV в подвижной Mesh-сети LoRa

Исследование протокола маршрутизации **AODV** (Ad hoc On-Demand Distance Vector, RFC 3561) для нашего кейса: **до 20 подвижных узлов** на радио LoRa. Блокнот сделан на основе общего симулятора `theory/mesh_routing_simulation.ipynb`. Модель радио, канала, узла и ядро симулятора те же, что в исходнике. Добавлены AODV, топологии нашего кейса, метрики под требования и эксперименты.

**Как пользоваться**

1. Выполните все ячейки сверху вниз: *Kernel → Restart & Run All*. Результаты экспериментов уже сохранены в `results/*.csv`, поэтому полный прогон занимает около минуты.
2. Чтобы пересчитать всё заново, поставьте `RERUN = True` в первой ячейке раздела 10. На одном ядре это около 40 минут.
3. Параметры собраны в ячейках с пометкой ⚙️. Параметры AODV и готовые варианты `aodv_rfc`, `aodv_rfc_hello`, `aodv_lora` находятся в разделе 4.1.

Зависимости: Python 3.10+, `pandas`, `matplotlib`.
